# 真机验收清单

下面每条都要在你自己的电脑上做。仓库里的测试用的是录制命令输出和演示窗口，没有真的改过路由。演示窗口顶部写着「演示数据」。

每一步之前先看预览。预览还在、你还没点按钮时，另开一个终端看路由，它应该和打开程序之前一样。取消授权窗口之后，路由也必须不变。

## Windows 10 / 11

准备：有线、Wi-Fi、手机 USB 共享同时连上。如果开了 Clash Meta / mihomo，先记下它的 TUN 名字（常见是 Meta）。

1. 打开程序（不要右键「以管理员身份运行」整个窗口）。列表里要有三张物理网卡，类型分别是有线、Wi-Fi、USB 共享，并有 IPv4 和网关。IPv6 只是一行说明。
2. 点 Wi-Fi，只看预览。预览要写出接口跃点从多少到多少，并写明不改 Meta、Hyper-V、VMware。此时再运行 `route print -4`，跃点应还没变。
3. 点「设为默认出口」，在 UAC 里同意。然后再看 `route print -4` 或 `Get-NetIPInterface -AddressFamily IPv4`，Wi-Fi 的 IPv4 跃点应变成 1，其他物理网卡变高。用浏览器打开一个网页，确认走的是 Wi-Fi。
4. 用同样的方法改到有线，再改到 USB 共享。每次都先看预览。
5. 点「恢复到更改前」。跃点应回到第一次点击之前。若当时是自动跃点，应重新变成自动。
6. 再点「自动」。已经是自动时，预览应说明不用改。
7. 打开 mihomo / Clash Meta 的 TUN。列表里它应标成 VPN/TUN，单选按钮是灰的，顶部说明流量仍会进 TUN。再把物理出口从 Wi-Fi 改到有线：TUN 自己的跃点不变，代理进程还在。物理网卡的跃点按预览变化。关掉 TUN 之后，默认路由应落到你刚选的那张物理网卡。

## macOS（Apple Silicon，M1 或更新）

准备：系统设置里能看到 Wi-Fi、有线或 USB 网卡、iPhone USB。首次打开未签名应用时，按住 Control 点应用再选「打开」。

1. 打开程序，不要用 sudo 启动窗口。列表按网络服务显示，当前默认路由应和 `route -n get default` 的 interface 一致。
2. 点另一张物理服务。预览给出完整的旧顺序和新顺序，Shadowrocket / Clash 等服务还在列表里，只是物理服务被放到第一位。
3. 点应用，输入管理员密码。然后运行 `networksetup -listnetworkserviceorder`，第一项应是你选的服务。
4. Wi-Fi、有线、iPhone USB 各切一次。USB 网卡（USB 10/100/1000 LAN 这类）应显示为有线，而不是手机共享。
5. 点「恢复到更改前」，服务顺序回到第一次切换前。再点「自动」，在还没改过或已经恢复时，应说明当前就是那份顺序。
6. 打开 TUN 后再切一次物理服务。`route -n get default` 在 TUN 开着时仍可能是 `utun*`。程序要标明这件事，并且不要把 utun 设成出口。关掉 TUN 后，默认接口应跟着你排好的服务顺序。

## Ubuntu

准备：桌面版，NetworkManager 在管有线 / Wi-Fi / USB 共享。不要用 sudo 打开界面。

1. 列表里的类型、IPv4、网关和 `ip -4 route` 对得上。当前默认路由若是 tun/Meta，物理网卡里跃点更低的那张应标成「物理优先」。
2. 点另一张物理网卡。预览写的是 `ipv4.route-metric` 的旧值和新值，并提醒重新应用时可能闪断。点应用，`pkexec` 只弹出一次。然后 `nmcli -g ipv4.route-metric connection show "连接名"` 和 `ip -4 route` 应能看到新跃点。
3. Wi-Fi、有线、USB 共享各切一次。手机共享应标成 USB 共享；USB 千兆网卡应标成有线。
4. 点「恢复到更改前」，metric 回到第一次修改前（自动一般是 -1）。再点「自动」，手动改过的连接回到 -1，本来就是自动的不要被改成别的数。
5. 若某张网卡不由 NetworkManager 管理，预览必须改口说用 `ip route`，并写明重启后可能丢失。这种情况只在你有这种网卡时测。
6. 打开 mihomo / sing-box 的 TUN。它应标成 VPN/TUN 且不能选。再切物理网卡时，TUN 的 metric 不变，代理不被关掉。关掉 TUN 后，默认路由落到刚选的物理网卡。

## 三套系统都要看的失败情况

- 授权窗口点取消：程序说明没改成，路由和打开前一致。
- 预览里出现的命令只有跃点、服务顺序或默认路由，没有 DNS、没有关闭进程。
- IPv6 地址有变化也不该由这个程序造成。
